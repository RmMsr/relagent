# Goals

## Relagent Motivation

This project was created to explore how useful an open-source, self-hosted AI assistant can be without compromising privacy.

## Guiding principles

### Data sovereignty

All data is processed and stored within the system (engine and frontend). If an external service is used, it needs to be explicitly enabled or allowed by the user. For example a web search or interaction with a 3rd party AI.

- Pure local execution and storage
- No external services for core functionality
- Works offline (without or with restricted internet access) as long as frontend and engine can comminicate

### Open and transparent

This tool should be as easy to understand and re-use as possible.

- 100 % open source
- Usage of free and open weights AI models
- No hidden features or capitalizing of user data

### Low barrier to entry

It requires some technical expertise, effort and resources to run an AI agent yourself, but it should be in reach for as many people as possible.

- Reasonably easy and affordable to run on local hardware
- Requires mid-class consumer grade graphics card
- Works on most mobile Android or iOS devices or desktops
