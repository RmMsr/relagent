# Vision

This is a the rough idea where this project might be heading. It is given to guide development and architecture in choosing a good path.

## Use cases

Relagent is a daily assistant you can interact with using text and voice. Maybe visual content. The agent is available via an mobile phone app. It can be used actively while holding the device or handsfree.

Key features:
- Answering questions or having discussions (LLM chat)
- Speech recognition, synthesis and voice activation (on device language models)
- Looking up information from the internet (web search)
- Initiating calls or accessing calendar or contacts (device access, voice commands)
- Using local data to persist and retrieve memory (local storage, RAG)
- Accessing additional services locally or 3rd party (via MCP) or even refer tasks or questions to a more capable AI
