# Review Architecture

Use the Task tool with subagent_type='project-architect' to perform a comprehensive architectural review of the Relagent Flutter application.

The review should:
1. Assess how well current code aligns with Riverpod best practices
2. Identify any technical debt or architectural inconsistencies
3. Evaluate state management patterns across the codebase
4. Check for opportunities to simplify or refactor code
5. Ensure adherence to the project's development principles (simplicity, privacy, accessibility)
6. Provide actionable recommendations for improvements

Focus on the apps/lib directory and consider the guidance in apps/CLAUDE.md and docs/development.md.
